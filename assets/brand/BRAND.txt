Pathwarden brand: Crown W

One node path that reads as a W for Warden and as a crown for Tier Zero:
violet end nodes, a green crown jewel, a violet-to-green path and a crown band.
Tagline: Defend every path to privilege.

Colors
  On dark (#0B0E14 navy): violet #9D5CFF, green #7CE46B, band #F7F7F7.
  On light (#F7F7F7):     violet #6B00D6, green #1F8A3A, band #0B0E14.
  Alarm (jewel when Tier Zero is reached): #B57BFF on dark, #6B00D6 on light.
  Never red: red belongs to severity, not the brand.

Decisions
  - Flat valley floors: the W's valleys are trimmed flat, parallel to the band.
  - The jewel is neutral grey while paths draw, alarm violet when a path
    reaches Tier Zero, green when it is protected. At rest it is green.
  - Headers (the app's rail, the report) pulse every 6 s after the intro; the
    README banner keeps the brand file's 4 s.
  - Raster favicons and app icons sit on a navy tile; favicon.svg has no tile
    and switches to the light colors on light browser UIs.
  - Everything animated is still under prefers-reduced-motion.

Sizes
  16 to 32 px: the small cut (mark/mark-small-*.svg, heavier strokes on a
  4-unit pixel grid). 48 px and up: the regular cut (mark/mark-*.svg).

Files
  mark/      marks: dark, light, glow, mono-dark (white), mono-light (navy)
  lockup/    horizontal and stacked, with and without the tagline; outlined
             (safe anywhere) and -live (real text, Inter or system fonts)
  animated/  README banners and transparent marks; pure CSS, so they animate
             in a GitHub README <img>
  social/    Open Graph card (1200 x 630) and README banners (1280 x 400)
  favicon/   favicon.ico/.svg, PNGs, apple-touch, PWA and maskable icons
  inline/    the mark and wordmark the app and the HTML report inline (colors
             and motion from CSS classes in report.css; the mark carries
             the animated brand files' feGaussianBlur glow, scaled for ~34 px)
  cli/       the terminal logo as the CLI draws it: pathwarden-cli.ans (hero,
             truecolor) and pathwarden-cli-ascii.txt (the 7-bit fallback);
             drawn by crates/pathwarden-cli/src/logo.rs, refreshed by
             scripts/docs-media/cli_logo.py
  The Windows icon is crates/pathwarden-cli/assets/pathwarden.ico.

Rebuilding
  Every file here is generated by scripts/brand (a copy of the brand source,
  pathwarden-brand/crown-w/src, repointed at this folder):
    python scripts/brand/build_static.py   marks, lockups, social, favicons
    python scripts/brand/build_anim.py     animated SVGs (--previews: GIF/MP4)
    python scripts/brand/build_repo.py     icon, inline SVGs, terminal banners
  Needs Python with cairosvg, Pillow, fontTools and uharfbuzz, Inter Bold
  (PATHWARDEN_INTER_BOLD=path\to\Inter-Bold.ttf if not installed), and Node 22+
  with Chrome or Edge for the blurred PNGs.

Wordmark: Inter Bold, SIL Open Font License 1.1, outlined in the files.
